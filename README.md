# SimFyCanvas

Flutter desktop whiteboard with a retained-mode scene graph and a modern (non-sketchy) look.

## Features

- Tools: select, pan/zoom, rectangle, ellipse, diamond, line, arrow, freehand, text
- Transform handles (move, resize, rotate; multi-select uniform scale)
- Undo/redo, grid, JSON scene I/O, PNG export

## Run

```bash
flutter run -d windows
```

## Test

```bash
flutter test
```
